# Project Title
This Is a SuperMarket Simulator game made in python

# Description
This game is a simulator where the user scans items by either pressing enter or by enter the unique PLU code each item has
(only for produce items). The User also has a way to reset their save file and also features an upgrade shop, a master key and a handbook. the user keeps playing until all the customer's have been served and moves on the the next Shift. This game is infinite and only stops if the user exits or enters the number specified for exiting.
